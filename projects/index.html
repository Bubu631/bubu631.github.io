Amap POI Agent

Command-line itinerary planner

Plans up to three stops for a city, starting point, time budget and interests through the Amap MCP tools. A model-driven tool loop with a step limit searches places and routes; a verification layer then checks place identifiers, addresses, distances and times against the tool responses, drops places the tools never returned, and records failed calls. A rules planner provides a fallback over the same evidence.

  • Python
  • MCP client (SSE, stdio)
  • LLM tool calls
  • asyncio
  • httpx

HPAC Rowpack

Lossless archive repacking

A reversible encoding for the signed integer weight rows in an HPAC video-compression archive. Rows are grouped by bit width, zigzag-coded and written as bitplanes ahead of the existing LZMA stage; the decoder restores the original model bytes and checks them before the inherited renderer runs. Reconstruction tests are included, and the repository documents which components are inherited.

  • Python
  • NumPy
  • LZMA
