# Shengwei Zhang

Personal engineering and research portfolio for Shengwei (Jacob) Zhang.

**Website:** https://shengweizhang.com/

The home page opens with a short introduction and a portrait, then maps four technical capabilities to the projects that demonstrate them, presents four selected engineering projects, lists four research manuscripts, and closes with a short About section. A separate Projects page lists every public project under its own name. A downloadable portfolio PDF is included.

## Files

- `index.html`: home page with the hero, technical focus, selected projects, research, and About.
- `projects/index.html`: all public projects with stacks and links.
- `styles.css`: shared responsive layout and typography.
- `assets/fonts/`: self-hosted Inter, Instrument Serif and JetBrains Mono (Latin subsets, SIL Open Font License 1.1).
- `assets/img/`: the hero portrait, interface screenshots and paper figures.
- `demos/tool-dependency-graph.html`: generated output of the Tool Dependency Graph utility on its synthetic catalog.
- `Shengwei_Zhang_GitHub_Portfolio.pdf`: downloadable portfolio.
- `CNAME`: custom domain for GitHub Pages.
- `.nojekyll`: serves the static files without Jekyll processing.

## Update the site

Edit the HTML or CSS and push to `main`. GitHub Pages publishes the repository root. No package installation or build step is required.

For a local preview, run `python3 -m http.server 8000` in this directory, then open `http://localhost:8000`. The pages use root-relative paths, so serve the directory instead of opening the files directly.

## Sources for the content

Screenshots show each project's own interface running on its bundled example data. Paper figures come from the corresponding research repositories.
