01 FastAPI service

Clinical Trials Visualization

A FastAPI service that turns a question about ClinicalTrials.gov into chart-ready data.

Problem
A chart of registry counts is hard to trust when you cannot see which studies produced each bar or point.
Implementation choice
The planner, either a rules grammar or an OpenAI model held to a strict JSON schema, only emits a typed query plan. Python retrieves, deduplicates and aggregates the studies, and attaches the NCT IDs and source field paths to every observation.
Verified by
137 automated tests covering planner behavior, upstream errors, aggregation, evidence and the HTTP contract.

  • FastAPI
  • Pydantic
  • httpx

02 Browser app and engine

Proofwork

A review workflow that keeps a workpaper adjustment connected to its evidence and history.

Problem
When a reviewer corrects a number in a tax workpaper, the link to the source pages and to earlier sign-offs is easily lost.
Implementation choice
A deterministic engine flags a repeated scan by comparing normalized page text, since matching totals alone prove nothing. Each adjustment stores the original value, the actor and the reason, and a material change invalidates sign-offs made on the earlier revision.
Verified by
A runnable example on invented records, engine tests, and a hosted prototype of the full browser workflow.
  • TypeScript
  • React 19
  • Vite
  • Zod
  • Node test runner

03 TypeScript utility

Tool Dependency Graph

Infers which tool can supply the input that another tool requires.

Problem
With a large tool catalog, an agent has to work out which call returns the identifier that the next call needs.
Implementation choice
Links are inferred offline from schema metadata at field level, comparing types, resource names and nesting. An order comment id is therefore never matched to a product comment id.
Verified by
Tests on a synthetic shop catalog, which produces 9 tools and 7 dependencies, and on a second toolkit through the CLI.
  • TypeScript
  • Node.js
  • JSON Schema

04 Python and SQLite, synthetic records

Clinical Record Abstraction

Turns plain-text clinical notes into reports in which each figure cites its source lines. Runs on synthetic records.

Problem
Two signed notes about the same visit can disagree, and a single reported total hides that conflict.
Implementation choice
When credible records support different durations, the report keeps the range and does not pick one. Ingestion deduplicates documents by SHA-256 content hash into SQLite, and an unsigned draft stays visible as administrative evidence without being counted.
Verified by
The bundled example returns 2 sessions and 60–70 minutes with a document and line reference per encounter; tests cover range preservation, repeat ingestion and exact source lookup.
  • Python standard library
  • SQLite
  • unittest

Research

Model evaluation, selection bias and measurement under a budget

Four manuscripts, each in its own repository with code, configurations and recorded results.

Certifying Model Upgrades with Slice-Wise Non-Regression and Incumbent Fallback

Shengwei Zhang, Tao Wu, Fei Qian

Studies how to certify a model upgrade without degrading important data slices. Uses paired non-inferiority tests and keeps the exact incumbent model when the evidence is insufficient. Includes controlled simulations, public digits experiments, saved checkpoints and validation tests.

  • Python
  • NumPy
  • SciPy
  • scikit-learn

ManuscriptRepository

When Edit Localization Amplifies Relative Selection Bias: Gradient Geometry, Target Mismatch, and Importance Weighting

Shengwei Zhang, Haoda Dai, Yifei Li, Yuheng Song

Investigates how learning from selectively observed human corrections changes gradient bias and the training target. Combines mathematical analysis, importance weighting, Monte Carlo experiments and fixed-checkpoint diagnostics on public translation post-edits with pretrained models.

  • Python
  • PyTorch
  • Hugging Face Transformers
  • NumPy

ManuscriptRepository

Which Uncertainty Is Worth Reducing? Budgeted Measurement for Wellbeing Prioritisation

Shengwei Zhang

Studies which additional measurements are worth acquiring before prioritising units for wellbeing review. Evaluates budget allocation across two measurement channels with controlled simulations, a public BRFSS replay and an NHS staff survey illustration.

  • Python
  • pandas
  • SciPy
  • Matplotlib

The Audit Complexity of Group-Relative Policy Updates

Shengwei Zhang

Studies how many reference labels are needed to recover a fixed group-relative policy update. Includes query-complexity theory, randomized estimators, controlled simulations, small-policy training and frozen-model diagnostics on historical software-agent trajectories.
